    Menyediakan…

    Mod AI memuat turun model (~40 MB) pada penggunaan pertama, kemudian disimpan dalam cache pelayar. Pemprosesan tetap berlaku pada peranti anda.

    Soalan lazim

    Adakah imej saya dimuat naik ke pelayan?

    Tidak. Semua pemprosesan berjalan di dalam pelayar menggunakan Canvas, WebAssembly dan WebGL/WebGPU. Tiada API pemprosesan imej dipanggil.

    Kenapa mod AI perlu muat turun fail besar?

    Model segmentasi (~40 MB) diperlukan untuk memisahkan subjek daripada latar. Ia dimuat turun sekali dari CDN awam dan disimpan dalam cache pelayar, jadi penggunaan seterusnya lebih pantas.

    Bagaimana naik taraf berfungsi?

    Imej diresample dengan algoritma Lanczos (pica) dan diberi sedikit unsharp mask untuk mengekalkan tepi. Ia bukan penjanaan butiran baharu seperti model super-resolution.

    Format apa yang disokong?

    Input: JPG, PNG, WebP, GIF (bingkai pertama), HEIC jika pelayar anda menyokongnya. Output: PNG untuk semua hasil (mengekalkan ketelusan).
