    Soalan lazim

    Adakah imej saya dimuat naik ke pelayan?

    Tidak. Semua pemprosesan berjalan di dalam pelayar menggunakan Canvas, WebAssembly dan WebGL. Tiada API pemprosesan imej dipanggil, dan tiada fail dihantar keluar daripada tab ini.

    Kenapa mod AI perlu muat turun fail besar?

    Model segmentasi (~40 MB) diperlukan untuk memisahkan subjek daripada latar. Ia dimuat turun sekali dari CDN awam dan disimpan dalam cache pelayar, jadi penggunaan seterusnya lebih pantas.

    Bagaimana naik taraf berfungsi?

    Dua enjin. Lanczos menggunakan resample pica + unsharp mask — pantas dan sesuai untuk imej besar. AI menggunakan model ESRGAN (UpscalerJS) yang menjana butiran baharu pada skala 2×; imej diproses dalam jubin 256 px dengan pertindihan supaya memori terkawal dan tiada garis sambungan.

    Format apa yang disokong?

    Input: JPG, PNG, WebP, GIF (bingkai pertama), HEIC jika pelayar anda menyokongnya. Output: PNG jika imej ada ketelusan, JPEG 0.92 jika tidak.
